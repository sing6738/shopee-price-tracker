# 🛒 Shopee Price Tracker

ติดตามราคาสินค้า Shopee แล้วส่งรายงานมาที่ Discord  
ไม่ต้องคอยเปิดแอปเช็คเองทุกวัน

## ทำไมถึงสร้าง
อยากซื้อของแต่ไม่รู้ว่าราคาตอนนี้ดีแล้วหรือยัง  
เลยสร้างตัวนี้ขึ้นมาให้คอยดูแทน

## ฟีเจอร์
- ดึงข้อมูลราคาจาก Shopee API
- แสดงราคาปัจจุบัน ราคาก่อนลด สต็อก และคะแนน
- รองรับหลาย URL พร้อมกัน
- ส่งรายงานผ่าน Discord Webhook

## เทคโนโลยีที่ใช้
- Python
- Shopee API
- Discord Webhook

## วิธีติดตั้ง
1. ไม่ต้องติดตั้ง library เพิ่ม ใช้ได้เลย
2. เปิดไฟล์แล้วใส่ค่าของตัวเอง
   DISCORD_WEBHOOK_URL = "Discord webhook ของคุณ"
3. ใส่ URL สินค้าที่อยากติดตาม
   shopee_urls = ["url สินค้า 1", "url สินค้า 2"]
4. รันโปรแกรม
   python shopee-price-tracker.py
